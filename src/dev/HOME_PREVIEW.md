# 홈 대시보드 디자인 확인

- `/home?preview=default`: 기본 홈 디자인 예시 (일정 미설정 4개, 관리 예정일 없음)
- `/home?preview=scheduled`: 지연·오늘·임박·예정 항목과 별도 미설정 영역
- `/home?preview=empty`: 등록 항목이 없는 홈

`preview` 매개변수는 개발 모드에서만 사용하며, 잘못된 값은 기본 화면을 표시합니다.
날짜는 피그마와 맞춘 11월 7일의 고정 예시입니다. 현재 날짜나 실제 일정과 연결하지 않습니다.
표시 데이터는 목록 화면의 임시 데이터를 재사용하여 항목 이름과 ID를 일치시킵니다.
상태·날짜 계산, 완료 기록, localStorage 저장은 구현하지 않습니다.
추가·목록·상세·기록·수정 링크는 기존 경로의 화면으로 이동합니다.

현재 데이터 연결 범위와 미리보기 분리는 [DATA_CONNECTION.md](./DATA_CONNECTION.md)를 참고하세요.

실제 `/home`은 저장된 기록·주기와 로컬 오늘 날짜를 사용해 상태를 계산합니다. 홈·목록은 같은 Service 우선순위로 정렬하며 MAINTENANCE.md를 참고하세요.
