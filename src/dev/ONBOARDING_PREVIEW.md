# 온보딩 기능 및 디자인 확인

## 실제 온보딩

- `/`: 저장된 완료 여부를 확인하고 미완료라면 진행 중인 단계·입력 초안을 복원합니다.
- 입력·선택·단계 이동 시 초안을 저장합니다. 직접 추가한 공간·항목도 복원합니다.
- 최소 공간 1개, 전체 관리 항목 1개를 선택해야 완료할 수 있습니다.
- 주기는 비우거나 양의 정수를 입력합니다. 마지막 관리일은 선택이며 오늘·과거 날짜만 허용합니다.
- '기억나지 않아요' 선택 또는 빈 관리일이면 초기 기록을 만들지 않습니다.
- 완료 시 Space, Item, initial History 및 완료 상태를 함께 저장한 뒤 `/home`으로 이동합니다.
- 완료된 사용자의 `/` 접근은 `/home`으로, 미완료 사용자의 메인 서비스 접근은 `/`로 이동합니다.
- 완료 저장 실패 시 입력을 유지하고 재시도할 수 있습니다. 초안 저장 실패도 별도로 알립니다.

## 개발용 디자인 미리보기

- `/?preview=welcome`: 시작 화면
- `/?preview=spaces`: 공간 선택
- `/?preview=items`: 욕실 기본 항목 선택
- `/?preview=cycles`: 주방·욕실 4개 항목의 주기 설정
- `/?preview=custom`: 직접 추가한 공간·항목

위 개발용 미리보기는 완료 여부와 무관하게 접근할 수 있으며, 실제 사용자 데이터와 초안을 변경하지 않습니다. 완료 버튼도 저장하지 않고 미리보기 안내만 표시합니다.
기본 공간 5개와 관리 항목 22개는 기존 정적 파일을 참조합니다. 기본 콘텐츠 ID와 실제 Item ID는 분리합니다.

## 저장 중단 복구

`homeguide:pending-onboarding`은 네 데이터 키의 이전 원본을 잠시 보관하는 복구 키입니다. 전체 저장 성공 후 제거합니다. 중간 실패 시 이전 원본으로 복구하고, 앱이 강제 종료된 경우 다음 로딩에서 복구합니다. 복구도 실패하면 기록을 보존하고 다시 불러오기를 안내합니다.
복구 키는 정상 사용자 데이터나 기본 콘텐츠 저장소가 아닙니다.

## 검증

자동 테스트와 서버 렌더링으로 저장 모델 변환·초안 재조회·복원된 폼·접근 정책·저장 단계별 실패 복구를 확인했습니다.
실제 브라우저 클릭, 새로고침, 뒤로가기, 모바일 배치는 브라우저 연결 오류로 아직 확인하지 못했습니다.
관리 대상 저장·수정·삭제는 4단계에서, 관리 일정 계산은 5단계에서 연결했습니다. 기록 작성·수정·삭제도 6단계에서 연결했습니다.
