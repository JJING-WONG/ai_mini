# 관리 대상 목록 디자인 확인

개발 서버에서 아래 주소를 확인합니다.

- `/items`: 피그마 기본 목록 (미설정 항목 4개)
- `/items?preview=scheduled`: 관리 상태 5종
- `/items?preview=empty`: 전체 빈 목록

`preview` 매개변수는 개발 모드에서만 사용합니다. 배포 빌드에서는 기본 목록을 표시합니다.
공간 버튼은 표시되는 임시 목록만 전환합니다. 추가·상세·관리 완료 링크는 기존 임시 페이지로 이동합니다.
임시 데이터는 `src/features/items/data/itemsPreview.js`의 표시 전용 데이터이며 저장·일정 계산·완료 기록을 수행하지 않습니다.
