# CONTENT_SPEC.md

## 1. 문서 목적

본 문서는 자취방 설명서 서비스에서 제공하는 기본 관리 콘텐츠의 구성과 관리 정책을 정의한다.

서비스의 주요 목적은 자취 초보자가 평소 놓치기 쉬운 주거 관리 항목을 발견하고 자신의 생활 환경에 맞는 관리 일정을 설정하도록 돕는 것이다.

## 2. 기본 콘텐츠 구성

- 기본 공간: 5개
- 기본 관리 항목: 22개
- 공간: 주방, 욕실, 세탁 공간, 생활 공간, 현관
- 관리 유형: 청소, 점검, 교체
- 콘텐츠 정보 수준: B. 기본 설명 포함

각 기본 관리 항목에는 다음 정보를 제공한다.

- 관리 항목 이름
- 관리 필요성
- 권장 관리 주기
- 주기의 근거 유형
- 적용 조건 및 주의 문구
- 출처 이름과 URL

## 3. 관리 주기 정책

### 3.1 공식 안내 기반 (official)

제조사 또는 전문기관에서 제시한 관리 주기를 참고한다.

특정 제품에 대한 안내를 모든 제품에 공통 적용되는 기준으로 설명하지 않는다.

### 3.2 서비스 참고값 (suggested)

공식 자료에 일률적인 주기가 없지만 서비스에서 참고 주기를 제안할 필요가 있는 경우 사용한다.

사용자에게 공식 권장 주기와 구분하여 표시한다.

### 3.3 사용자 설정 (user)

신뢰할 만한 공통 주기가 부족하거나 제품별 차이가 큰 경우 적용한다.

기본 주기는 null로 저장한다. 사용자가 직접 주기를 설정할 수 있다.

## 4. 기본 관리 항목 등록 정책

1. 사용자는 자신이 선택한 공간에 해당하는 기본 관리 항목을 확인한다.
2. 실제 주거 환경에 존재하는 항목만 선택한다.
3. 기본 권장 주기가 존재하면 초기값으로 제공한다.
4. 사용자는 초기 주기를 자유롭게 수정할 수 있다.
5. 기본 주기가 없으면 직접 입력하거나 미설정 상태로 등록할 수 있다.
6. 등록된 관리 항목은 기본 콘텐츠와 독립적인 사용자 데이터로 저장한다.

## 5. 일정 계산 정책

- 관리 주기 단위는 일(day)이다.
- 마지막 관리일은 연결된 관리 기록 중 가장 최근 날짜로 계산한다.
- 다음 관리일 = 마지막 관리일 + 관리 주기
- 마지막 관리일이나 관리 주기가 없으면 다음 관리일은 미설정으로 표시한다.
- 관리 주기를 변경하면 다음 관리일을 다시 계산한다.
- 기본 콘텐츠의 권장 주기가 변경되더라도 기존 사용자 설정을 자동으로 덮어쓰지 않는다.

## 6. 콘텐츠 검증 정책

1. 출처의 원문과 URL을 확인한다.
2. 해당 주기가 적용되는 제품 유형을 기록한다.
3. 출처에 없는 주기를 공식 권장값으로 표시하지 않는다.
4. 월간 주기를 30일로 환산한 경우 근사값임을 표시한다.
5. 출처가 확인되지 않은 항목은 공식 주기로 등록하지 않는다.
6. 전기 설비와 화재 안전 관련 항목은 제품 설명서와 관리 주체의 지침을 우선한다.

## 7. 구현 시 고려사항

- 기본 콘텐츠는 정적 JavaScript 데이터로 관리한다.
- 사용자 관리 항목은 localStorage에 별도로 저장한다.
- 기본 콘텐츠의 ID는 안정적으로 유지한다.
- 사용자 데이터와 기본 콘텐츠는 templateId로 연결한다.
- 기본 콘텐츠에 없는 사용자 지정 항목도 등록할 수 있다.
- 사용자가 직접 추가한 항목은 출처 정보가 없어도 정상적으로 동작해야 한다.
